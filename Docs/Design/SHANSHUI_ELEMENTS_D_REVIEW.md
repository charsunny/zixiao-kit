## 阶段 C 两项返工

- 主山保留宽底、主宾峰和原来的 `LayerFade`。披麻／解索长皴沿山脉成束，起笔错开；谷地和背光侧密，受光面和峰尖疏。谷地分层染墨，山腹补随轮廓渐变的淡染，山头矾头有勾有皴，山脊加不等距苔点与小树。
- 山居另用 `paintingRockyStream`：泉口贴实岸石缝，三至四组前后搭接的石岸夹出窄水，石唇下留白、短跌水线和短横水纹，稍向近处放宽。图谱有独立六种子行。桥下已验收的河道、桥墩倒影和水乡落屋算法保持原画法。
- 长皴增加后曾超过 600,000 点预算。只对主山内部路径采用 0.16 原始单位的误差约束简化；山体第一条承托轮廓保持精确，墨量、长皴和透明度保留。

## 阶段 D 改动

- **共用天象**：日、月、残月、星、雨、雪由图谱和场景共用 `paintingAtmosphere`；日为无光晕朱砂圆，局部云边遮掩；月用不对称淡云托纸白，残月有不同盈亏；星点稀疏，雨丝有方向和疏密，雪用纸白小片。明暗纸色走同一个转换入口。
- **词表**：补人家／村舍／柴门、茅屋／茅舍／草堂、老树／古木／古树、流水／春水／溪水、亭、塔、舟船、驴。过滤词牌造成的桥、雨、月误判，避免“月亭”“亭亭”误中独立亭子；《晓出净慈寺》归荷塘，不因标题的“寺”画成山寺。
- **荷态入配方**：小荷／初荷取初荷，残荷／枯荷／留得取残荷，其余取盛荷；状态写入 `SceneOptions`，换种子不会换季节，旧配方缺字段仍可解码。残荷诗不默认添蜻蜓，显式写了蜻蜓才画。已验收三种荷的绘制函数没有改。
- **驴**：沿用白描马的骨架，新增长耳、短身选项；默认马的三态和随机数路径不变。
- **秋思**：画老树、缠藤、枝上栖鸦与附近飞鸦；桥跨流水，桥旁瓦屋；近景古道上人牵马，落日靠远山。屋的门洞和屋檐按真实多边形度量，和人、马、桥使用相通尺度。
- **选中必画**：补依附物和落位退让。炊烟先找屋顶，舟先找水面，白鹭落水岸，藤找实际树枝。普通景物先换可用落脚位置，再适度缩小，不把失败的落位标成完成。复合图元中的舟、河道中的流水、秋思老树兼寒林，记录实际已绘图元的对应范围。互斥日月先在配方中按明确优先级归一。
- **比例**：人物与实际门洞相称；屋檐为人高 1.3–1.8 倍，树为人高 3–8 倍，桥跨为人高 4–8 倍，马肩与人肩相称。保留原有落地、桥水、缆绳、峰顶承托和诗句避让检查。
- **构图随机性**：种子决定两段岸的宽窄、前后高差、主体树落位、主宾山组合和远山层数；再为荷塘、庭院、渔舟、海天、大漠改变荷丛、墙段、舟、石矶、日与烟的重心。主树和月夜、村居的主体建筑放大，仍保留整宽地带、诗句框、阅读页和推荐页的留白。

用户已通过的老树、寒林、花树、松、竹、草、三态荷、石、亭、残垣均未重写。旧 `shanshui@1`–`@4` 渲染路径和金标、`Package.swift` target 结构未改。
