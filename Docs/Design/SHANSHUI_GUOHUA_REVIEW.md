# shanshui@5 国画化审图记录

基线：PR #9（`feat/shanshui-taste`），本轮叠加分支 `feat/shanshui-guohua`。仅在 VPS 编写和审查；出图、编译、测试在 xistudio，未在 VPS 安装依赖。

## 取法

- 郭熙：主宾峰、山腰云气与高远。参考 [Met《树色平远》](https://www.metmuseum.org/art/collection/search/39668)及《早春图》的山脉组织。
- 倪瓒：一河两岸、水面留白、远树无枝。参考[故宫《容膝斋图》](https://theme.npm.edu.tw/exh109/Labels/digital/en.html)。
- 马远、夏圭：边角的虚实、斧劈皴、藏露。参考[故宫《溪山清远》](https://digitalarchive.npm.gov.tw/Collection/Detail/30?dep=P)。
- 马远[《水图》](https://www.dpm.org.cn/collection/paint/229607.html)：回波成组，远小近大，水纹有疏密，不铺满等距线。
- 王蒙、沈周：山块层叠、干笔皴擦、浓墨点提。参考[《庐山高》藏品说明](https://tcmb.culture.tw/zh-tw/detail?id=20081224000003&indexCode=BOCH_CountryCulture_61)。

只取法，不临摹作品。墨色与朱砂点缀保持既有约束。
