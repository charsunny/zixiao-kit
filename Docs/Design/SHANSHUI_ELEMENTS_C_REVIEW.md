# 景物系统阶段 C：树木、植物、山石

分支：`feat/shanshui-elements`。基线：阶段 B 已验收的 `elements-b8` / `82b55c0`。
本阶段只做计划 1.4、1.2 的主山／瀑布／石／沙丘，以及用户明确并入 C 的亭顶、残垣两项修正。

## 改动

| 项目 | 画法与变化 |
|---|---|
| 老树、寒林 | 退出旧 `tree06`，以有收分的枝干骨架重画。老干粗、扭曲、有瘤节，区分蟹爪、鹿角、低分双干；寒林较细。图谱老树缩放由约 0.25 提高到 0.64。 |
| 枯藤、昏鸦 | 藤的绕干笔和悬垂段依附实际树干、枝肘；栖鸦落脚点来自同一骨架。秋思使用主老树，消除旧寒林兜底重复补树。鸦自身画法未改。 |
| 荷 | 宽叶、翻边、叶脉留白、直梗刺点。按用户追加要求，分初荷、盛荷、残荷：卷叶小叶与尖苞／大叶与花苞或开花／破叶折梗与莲蓬。混合行六种子覆盖三态，每态另画六个种子。蜻蜓跟随花苞、花或莲蓬的实际尖端定位。 |
| 花树 | 梅、桃式穿插枝干，花着生在小枝上，以五瓣圈花和点蕾表现，移除叶团。 |
| 竹 | 三至五竿，节间分笔，节点加重；三、四叶小组交错，前浓后淡，风向与竿数变化，留出空隙。 |
| 松 | 针叶成放射、扇形簇；树干加鳞皴；树冠层数、针簇位置和欹斜变化。 |
| 草 | 独立低矮点草，簇数、疏密和叶势变化，不再调用芦苇。 |
| 主山 | 去掉宽度压缩，底宽超过高的 0.45 倍（内部宽度下限按名义高度的 0.62 设置）；主峰配宾峰。用主脉、分叉支脉和肩石约束皴笔，受光面留纸，背阴处淡染；山头矾头、山脊疏密点树。登台保留真实水平承台面。宽底主山在窄屏推荐页缩小后，山脚建筑会沿现有岸面寻找低于山体中线的落脚位置。 |
| 石、礁 | 复用已验收的 `paintingStone` 三面石画法，分卧石、较高块石、前后双石。坡岸算法未改。 |
| 瀑布 | 窄一叠、宽一叠、二叠；两侧浓墨崖壁夹出纸白瀑流，下有溅雾、水口。场景按主山侧面定位，新增山涧接到已有溪的真实起点，山涧置于近岸和树木之后。 |
| 沙丘 | 两至四道长弧沙脊，受光侧留纸，背光侧淡染、干笔横擦；远沙脊为淡线。移除封闭纸色底，消除矩形硬边。 |
| 亭 | 攒尖顶实际高约 30、柱高约 50；檐口前后落差缩小，翼角微翘。歇山亭顶同步压低。 |
| 残垣 | 二至四段不同高度的断墙，保留局部平头，再沿不规则断口塌落；露砖层、墙头草、散砖。没有整齐雉堞，也避免三角尖顶像小屋。 |

保留柳、枫、杂树与芦苇画法。A 已验收的马、人物、鸟、坡岸、桥及倒影、溪流、水乡屋脚选择未重写。`paintingStone` 仅从私有改为内部可复用，函数内容不变。改动限定 `shanshui@5`，未改旧版本和金标、`Package.swift`。
