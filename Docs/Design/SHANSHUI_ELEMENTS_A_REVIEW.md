# 景物系统阶段 A 验收记录

本次只做 `SHANSHUI_ELEMENTS_ROUND.md` 第 6 节的阶段 A，等待验收后再进入 B。

## 改动

- 图谱：场景与图谱共用 `paintingAtmosphere` 和 `appendPaintingShapes`，统一日月配色；图谱取消整层正片叠底，避免把纸色重复叠成灰块。雨、落雪在当前代码中属于 App 天气层，图谱明确标注 `overlay`，不再把雪画成石头。瀑布仍复用当前场景画法，重画留在 C。
- 组合谱：新增 `testGroupReviewSheet`，七种组合各四个种子。直接调用生产场景生成器再裁取局部，不另造一套比例。显式选择茅屋、松、老树时，沿用村居与秋行的烟、篱笆、藤、鸦关系。
- 马：白描轮廓和极淡墨，勾出胯骨、肩、腹、耳、楔形头、屈膝与飞节、小蹄和尾；有站立低头、行走抬腿、低头吃草，兼有朝向、鞍具和墨色变化。秋行使用牵马组合，共用尺度、地面与缰绳；古道转折接到人马脚下。
- 人物：策杖、拱手、负担、坐观四式，随机朝向、斗笠和衣纹浓淡；头身约七头，衣纹勾形。渔翁使用坐姿并落回船身。
- 鸦燕：鸦群数量、大小、翅态变化；秋行树旁飞鸦和栖鸦合计三至五只，栖鸦脚落在实际树枝笔画上。燕有细长翅和剪刀尾，单只或成对；另加六种子 `crow.perched` 图谱。
- 桥：石拱、石板、木板三型，跨度、拱高、栏杆、过桥人变化；去掉桥头圆石团。桥、河道和倒影不再各自按包围框缩放，而用同一坐标和水位；拱下倒影来自同一条拱线，两端用岸线接回坡岸。
- 溪与河道：纸色留水，淡墨在岸外贴岸线，短横水纹贯穿桥下，可有少量勾线溪石；近宽远窄，走向、长河弯度和宽窄有变化。河道图谱不再固定相位。
- 坡岸：前后两三块不等宽土石，每块用纸色遮挡后块再画自己的轮廓和皴笔；取消嵌套的半透明肩形。皴笔沿背光面成束、缩短并疏密变化；点苔为横点簇；陡岸用平顶与立面折线，低岸分披麻与折带。
