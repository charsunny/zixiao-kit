# 传统色配色身份（2026-10）

2026-10-16 定。内核的身份体系（`ZXIdentity`：配色写在 JSON 里、必须写理由、内核不认识产品）再加七套随包配色，以及给 App 用的主题目录与选择组件。第一个接入方是微诗（第四稿起默认为鸦青），见 wish 仓库 `docs/THEME_PALETTES.md`；玄览、子晓以后按需选用。

## 1. 来源与边界

- 参照：[daodaolee/china-color](https://github.com/daodaolee/china-color)（384 色，按二十四节气排）。它**没有开源许可**，数据来自郭浩《中国传统色：故宫里的色彩美学》（中信出版社），色值、编排与部分色名有著作权。**只作灵感，不复制它的数据**：不拷 JSON、不照抄色值、不搬它的节气编排。
- 色名是公有的语词，古诗原文是公版。**每个用到的色名都要在微诗诗库里找到原句**，写进身份的 `rationale`（诗句 + 作者 + 篇名）。找不到原句的色名不用，换名。
- 色值自己调，以界面可读为准（见第 3 节的对比度要求）。

## 2. 七套配色（第四稿，2026-10-16）

用户看过三稿后定的原则：**主角是诗和画屏，配色不抢戏**。
- **底近中性**：不用米黄宣纸（退役），也不用粉彩染色；每套只有极轻的冷暖差别。深色底是真的深色。
- **颜色只在小处**：强调色（主色）用于选中、链接、作者名、主按钮；配色（secondary）用于标签与图表；朱印只占一小方。不铺大面积色块。
- **每套是一组有来历的搭配**，色名有诗句出处（见第 1 节）。

`鸦青` 是微诗的新默认（取代旧默认），也随包进内核，其他产品可选用。

## 3. 派生规则与测试

- **对比度**（随包身份一律测，单测遍历 `ZXBundledIdentity.allCases`）：正文（墨）对纸 ≥ 7:1；次级文字、强调、朱印、五支状态色对纸与 surface ≥ 4.5:1；`accentOn` 对强调 ≥ 4.5:1（深色多半是深字）。现有 `paper-ink-seal`、`monochrome-ink` 同样过这组测试。
- **派生**：surface 浅色比纸亮一档、深色比纸亮一档；border / rule = 墨 12% 叠在纸上；track = 墨 7% 叠在纸上；night = 深色纸再暗一档；secondary 以第 2 节第四稿的显式搭配值为准，不再按旧稿派生；状态色（success / warning / danger / info）与该套同族调过，满足上面的对比度。派生出的值写死进 JSON，不在运行时算。
- **`rationale`**：写出意象、色名出处（原句 + 作者 + 篇名）、各槽为什么这样取。
- **高对比度**：系统「增强对比度」打开时，沿用 `ZXColorTokens` 现有的处理；若某套在增强对比度下不达标，在该套 JSON 里补 `highContrast` 值（如需新字段，可选、缺省回落，旧 JSON 不受影响）。

## 4. 内核新增

1. `Resources/identities/` 加七个 JSON，`ZXBundledIdentity` 加七个 case（原始值即文件名）。内置身份 `sealText` 一律留空。
2. **主题目录**：`ZXPaletteCatalog`（名字可调整），列出可选配色：id、显示名、一句意象、浅深色样（纸、墨、强调、朱印），供 App 做选择页。目录只描述配色，不含档位；档位由 App 决定。
3. **套用到产品身份**：`ZXIdentity` 加一个方法，把某套随包配色的 `palette` 套进产品身份，保留产品自己的 `type`、`slots`（如微诗的字体与「微诗」印文），名字与理由合并。
4. **随节气**：`ZXSeasonTint` 的五季对应五套配色，按五行配色：春（木，青）→ 苍筤，夏（火，赤）→ 胭脂，长夏（土，黄）→ 缃叶，秋（金，白）→ 月白，冬（水，玄）→ 青黛。提供纯函数「季节 → 配色 id」。选「随节气」时不再叠加季节偏色（`seasonTint` 传 nil），避免偏两次。
5. **选择组件**：`ZXPalettePicker`：色样卡片网格（纸面上写一行字、强调色点、朱印小方），支持选中绑定、「随节气」一项（App 显式传入 season，显示当季色样与名称）、由 App 传入的上锁判断与点击上锁项的回调；无障碍读出色名与意象；支持动态字体与减弱透明度。
6. **测试**：第 3 节的对比度；每个 JSON 都能解码、七个 case 与文件一一对应；季节映射；套用产品身份后 type / slots 不变。

## 5. 第四稿实现记录

`ZXPaletteCatalog.entries` 以鸦青为首项，只列七套第四稿配色；`paper-ink-seal` 与
`monochrome-ink` 保留文件、case 和加载能力，但不出现在选择目录。对比度测试仍遍历全部九套身份。
七套的纸 / 墨 / accent / secondary / seal / muted 全部逐值按第 2 节；不把表内 muted 再用近似混色覆盖。
派生取 surface 浅色向白混 35%、深色每通道提高 8；border / rule 墨 12%、track 墨 7%；
night 为深纸每通道降低 5；四状态以 accent 向绿 / 赭 / 朱 / 黛的邻色混 80%，写死入资源。

鸦青已用只读 GET 接口核实：张矩《虞美人》“粉褪香腮零乱、鬓鸦青”，诗 ID
`4a0d028f-eb81-5af6-b2a5-8af79cc3ff83`。rationale 同时列出图标来源的四个原始色值。
所有名称的原句、作者、篇名与诗 ID 均保存在各自 rationale。
