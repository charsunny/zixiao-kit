## 改动

| 景物 | 本轮画法与变化 |
| --- | --- |
| house | 一至三间瓦屋，侧山墙、退后的侧墙，开门或合门、直棂小窗。墙角分笔，避免连续笔把房屋画圆。 |
| hut | 单间封闭茅舍、敞开草亭、带棚茅舍；毛糙出檐，不再与瓦屋共用画法。 |
| pavilion | 四角／六角攒尖、歇山；顶高约柱高六成，出檐约柱距 1.4 倍，粗细柱和低栏。 |
| pagoda | 五、七、九、十三层，楼阁式／密檐式，逐层收分和塔刹。 |
| templeGate | 独立歇山顶，中央拱门，一门／三门、长短侧墙、石阶。 |
| courtyard | 水平粉墙黛瓦，短转折墙；月洞门／矩形门、漏窗，去掉原来的斜地台。 |
| ruins | 两至四段断墙，砖层、缺口、断面与墙头草，退出旧卡通画法。 |
| cityGate | 垛口城墙、拱门洞、单檐／重檐歇山城楼，城墙长短变化，退出旧卡通画法。 |
| window / curtain | 直棂、方格、冰裂纹；横向竹篾、两条系带、卷边和拉绳，多个卷起高度。 |
| boat / mooredBoat | 纸白船身，线勾船舷与船底；长短舟、有篷／无篷、有人／无人。泊舟缆绳连到岸上木桩。 |
| angler / sail | 坐钓、立钓、带后篷渔舟；沿用已验收人物画法，添蓑衣和钓竿。硬帆有横向篾条，张帆面积变化。 |
| fence / terrace | 篱笆只改段长、疏密和缺口；古台只改低台高度、少量残损，图谱和峰顶共用台面画法。 |

## 比例和关系

- 月夜瓦屋预留首间窗洞，用房屋实际缩放把轩窗放进去，避免覆盖门扇。
- 竹帘的宽高随所在窗位生成，避免窄小的帘子悬在宽窗中。
- 村居取消原先相互穿插的第二间屋，由单座房屋的间数表达变化。
- 泊舟的船身、缆绳、岸桩分开记录；船的水面锚点仍取第一片船身轮廓。岸桩落在现有岸线上，并避开建筑。
- 保留用户的坡岸石分三面、溪口、水纹、桥墩倒影、水乡人家试落脚位置。相关地形和水的文件未修改；水乡落屋分支未修改。
- 未改旧版生成器、金标和 Package.swift；未改马、点景人物、飞鸦和栖鸦的画法。
